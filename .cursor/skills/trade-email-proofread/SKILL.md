# 英文商务外贸邮件审校

用户说出「检查语法错误」「检查语法」「语法错误」「检查拼写」「拼写错误」「检查用词」「校对邮件」「检查邮件」，或同类说法时，立即使用本技能审校用户给出的那封邮件。

先读取 [reference.md](reference.md)，再审校。一次只审一封邮件。只输出语言问题，不输出整封改写稿，不评价语气、礼貌或商务策略。

## 输入

审用户贴出的邮件，或用户指定文件中的一封邮件。同时给出多封时，回复「一次只审一封邮件。请指定要审的那一封。」然后停止。没有英文主题也没有英文正文时，回复「请贴出要审校的英文邮件主题和正文。」然后停止。正文全是中文时，回复「本技能只审英文商务邮件。」不输出两栏。

## 切开

1. 分出主题和正文。缺主题时，在报告前写「未提供主题。」缺正文时，在报告前写「未提供正文。」
2. 去掉签名。从正文末尾向前看：单独一行的 `--`，或单独成行且整行只有敬语的行，敬语为 `Best regards`、`Kind regards`、`Regards`、`Sincerely`、`Thanks`、`Thank you`，可以带逗号。该行及其后都是签名。开头或句中的 `Thank you for ...` 仍是正文。
3. 去掉已识别的引用历史：以 `>` 开头的行，或含 `On ... wrote:`、`-----Original Message-----`、`Forwarded message` 的区块，以及该区块之后的全部内容。
4. 引用边界不清时（写明是买方、客户或原始邮件的内容，但没有上述标记），这段不进入确定错误。待确认里保留原句，改法与原句相同，说明含「可能是引用历史」。`details as below` 后面的本人报价或规格不是引用历史。
5. 中英夹杂时，跳过中文句子，在报告前写「中文句子已跳过。」

签名和已识别的引用历史不出现在任一栏。

## 专名

以下专名保持原样，即使看起来像拼错。改法不得改动其中任何一个字符：

- 单号、发票号、合同号
- 型号、SKU
- 价格、币种
- 公司名、人名
- Incoterms：FOB、CIF、EXW、CFR、DDP 等
- 电子邮箱、网址、电话号码

专名周围的句子仍要检查。数量、交期和承诺留在句中检查。改法会改变数量、价格、交期、承诺、产品含义，或会把疑似地名改成另一个地名时，放入待确认。

行业用语见 reference.md，不单独标为错误。

## 检查

只使用五个类别。同一错误跨度只归一个类别，优先级从高到低：

1. 中式英语：冠词误用、时态与时间状语冲突、介词误用、中英误用词
2. 语法：一致关系、动词形式、句子结构
3. 标点
4. 用词搭配：词存在，但搭配不成立，且不属于中式英语
5. 拼写：单词拼错，且不是专名

礼貌套语不标，包括 kindly、hope you can、please help to、thanks in advance。

放入确定错误：改法只有一种，且不改变数量、价格、交期、承诺或产品含义。放入待确认：改法不止一种；改法可能改变上述事实；或无法判断是中式英语还是行业惯用语。待确认必须写明原因。

## 编号

正文第 N 句从 1 起。一句以 `.`、`?` 或 `!` 结束。小数点、型号中的点，以及 `Mr.`、`Ms.`、`No.`、`Inc.` 不是句界。单独成行、没有句末标点的问候语单独计为一句。中文句子不计入 N。主题整行是一个位置，不按句拆开。

同一句里位置不同的错误分成多条。每条改法只改自己这一处，句中其他错误保持原样。同一个错误跨度只出现一次。

## 输出

先写「确定错误」，再写「待确认」。两栏都要出现。空栏只写对应的一句：确定错误写「未发现确定错误」，待确认写「无待确认项」。有条目时按邮件顺序排列，主题在正文之前。每条固定这五项：

```
## 确定错误

1. 位置：正文第 1 句
   类别：语法
   原句：We has prepared the samples.
   改法：We have prepared the samples.
   说明：主语 We 与动词 has 不一致，应使用 have。

## 待确认

无待确认项
```

位置只写 `主题` 或 `正文第 N 句`。原句和改法用英文整句。说明用中文，一到两句。

用户同时要求重写全文或评价语气时，仍然只输出这两栏。

## 出报告前核对

- 两栏标题都在，空栏用规定原句
- 每条都有位置、类别、原句、改法、说明
- 类别属于上述五个词
- 改法只动一处，专名每个字符都未变
- 签名和已识别引用历史中的问题没有进入报告
- 待确认写了拿不准的原因
- 报告后面没有整封改写稿
